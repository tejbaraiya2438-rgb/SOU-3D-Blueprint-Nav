# 🏛️ Silver Oak University - Interactive 3D Blueprint Navigator

An interactive, web-based 3D Blueprint visualizer built with **Three.js** to solve campus navigation challenges for students, visitors, and faculty.

## 🚀 Key Features
- **3D Blueprint Aesthetics:** Isometric architectural style building mesh with wireframe styling.
- **Room-Level Precision:** 10 Floors with 10 individual clickable/interactive room blocks per floor.
- **Live Search & Highlighting:** Instant search for rooms, deans, and faculties with 3D canvas glow effects.
- **Real-time Info Cards:** View room allocations, faculty in-charges, and administrative details on tap.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **3D Engine:** Three.js (Orthographic Camera, OrbitControls, Raycasting)
- **Data Source:** JSON (`rooms.json`)

## ⚡ Quick Start
1. Clone this repository.
2. Run a local server (e.g., Live Server in VS Code or `python -m http.server`).
3. Open `index.html` in your browser.
